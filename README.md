# RM2k/2k3 游戏库

一个收录 RPG Maker 2000/2003 经典游戏的静态网站，由 GitHub Pages 托管。

- **全目录浏览**：27,000+ 款游戏，支持搜索、来源筛选、引擎筛选、排序
- **网页可玩**：精选经典 + 小型 VIPRPG 游戏，浏览器内直接运行（EasyRPG Player Web）
- **下载链接**：大部分条目附原始下载地址

## 本地开发

```bash
# 静态站根目录是 web/pages/
cd web/pages && python -m http.server 8000
# 打开 http://localhost:8000/
```

## 内容来源

- VIPRPG（日本 2ch VIP 同人社区，1~14代目保管库）
- rpgmaker.net（RMN）、rpgmakerarchive.com
- rmarchiv.de（德语圈）
- freem.ne.jp（ふりーむ）、itch.io
- 中文圈（九龙魔法阵等）
